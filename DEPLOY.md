# Cloudflare Pages deployment

1. In Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
2. Select `1983gulei-epiAI/gu-laboratory-website`.
3. Framework preset: None.
4. Build command: leave blank.
5. Output directory: `/`.
6. Deploy.
7. In Pages → Custom domains, add `gulaboratory.com` and `www.gulaboratory.com`.
8. Follow Cloudflare's DNS prompts and confirm HTTPS works on both hostnames.
9. Only after the new site is fully live, disable GoDaddy Websites + Marketing Basic auto-renewal.
10. Keep the `gulaboratory.com` domain registration active.
